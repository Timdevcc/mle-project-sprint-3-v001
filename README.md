Описание проекта
Микросервис на базе FastAPI для оценки стоимости объектов недвижимости по их характеристикам с использованием обученной модели машинного обучения. Проект включает полную инфраструктуру для локального развертывания, контейнеризации и мониторинга работы сервиса и модели в режиме реального времени.

Цели проекта
Разработка REST API для инференса ML-модели с валидацией входных признаков.

Упаковка приложения в изолированные Docker-контейнеры для воспроизводимости среды.

Развертывание мультиконтейнерной архитектуры через Docker Compose.

Настройка сквозного мониторинга инфраструктуры, прикладных метрик и качества предсказаний модели.

Используемые технологии
Бэкенд и ML: Python, FastAPI, Uvicorn, Pydantic, CatBoost / Scikit-Learn.

Контейнеризация: Docker, Docker Compose.

Мониторинг и метрики: Prometheus, Prometheus FastAPI Instrumentator, prometheus_client, Grafana.
